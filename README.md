# Mahawer Al-Aboor Website

A responsive bilingual website for **Mahawer Al-Aboor Transport Est.**, a construction material supply and transportation company.

## Services

- Soil supply
- Sand supply
- Stone and aggregates supply
- Block supply
- Asphalt supply
- Construction material transportation and delivery
- Operations and supply support

## Service Area

The website serves:

**Layla, Al-Aflaj, Riyadh Region, Saudi Arabia**

The location is connected to Google Maps:

[View on Google Maps](https://maps.app.goo.gl/6vLLS5ief4xegQfB7)

## Features

- Arabic and English language support
- Responsive desktop, tablet, and mobile layouts
- Construction material service listings
- Material image gallery
- Interactive Google Maps preview
- Contact section with phone, email, WhatsApp, Telegram, and Google Maps links
- Quote request form
- SEO metadata, sitemap, and robots.txt
- Accessible labels and external link security attributes
